# ComEdy Pricing 2.0

This branch (`v2`) contains the **2.0 rewrite**. `main` is unchanged — Netlify and GitHub Actions still run the original app.

## What’s new
- Live ComEd 5-minute prices (Chicago time)
- Zone-aware “what to do now” (paying you / cheap / normal / high / spike)
- Avg / high / low, 6h–30d chart, insights, recent readings
- **My Bills** from the real household PDFs (Apr 2025–May 2026)
- Press animations, number ticks, pull-to-refresh
- Sign-in (Google / X)

Source lives in [`v2/`](./v2).

The original PWA files (`index.html`, `app.js`, `styles.css`, GitHub Actions) stay on this branch so nothing from 1.0 is lost.
